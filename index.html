// 001 — What is Waymaster

INTELLIGENCE FOR IRON

BUILT FOR THE CLASSICS

Modern sat-nav belongs in modern cars. Waymaster is something different — a retro-styled navigation and vehicle intelligence system designed to feel native to the vehicles that inspired it.

Borrowing its aesthetic from 1970s and 80s computing — phosphor green displays, ASCII interfaces, vector graphics — Waymaster layers contemporary home-automation technology underneath a surface that belongs in a period-correct dashboard.

Route guidance, OBD-II vehicle diagnostics, temperature monitoring, fuel management — all presented the way they would have looked if this software had existed when your car rolled off the line.

Display Mode A

ASCII TERMINAL

Pure character-art interface. Every piece of information rendered in text, symbols and line art. Readable on any screen.

+--[ WAYMASTER ]--[ NAV ]--+ | HEADING : 247° WSW | | SPEED : 47 MPH | | NEXT : LEFT 0.3m | | ETA : 14:32 | | OIL TEMP : 82°C [OK] | | FUEL : ████░░ 68% | +--------------------------+
Display Mode B

GREEN VECTOR

Vector-drawn graphics on a phosphor green screen. Roads, compass arcs and instrument gauges rendered as luminous lines — like a 1983 arcade cabinet built into your fascia.
