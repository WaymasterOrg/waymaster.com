    <h1>FEATURES</h1>
    <p>Current Capabilities &bull; In Development &bull; Planned</p>
  </div>

<section class="section">
  <div class="container">
    <div class="features-grid">
      <div class="feature-card">
        <span class="feature-icon">▦</span>
        <h3>ASCII Terminal Display</h3>
        <p>Full character-art interface. Pure text rendering, readable on any display including low-resolution or vintage screens. Box-drawing characters, block elements, no bitmaps.</p>
        <span class="feature-status status-live">Live</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">⬡</span>
        <h3>OBD-II Vehicle Monitoring</h3>
        <p>Real-time engine data via OBD-II / CAN bus using ELM327-compatible adapters. Oil temp, coolant, RPM, fuel level, fault codes — displayed in period-correct gauges.</p>
        <span class="feature-status status-live">Live</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">◈</span>
        <h3>Turn-by-Turn Navigation</h3>
        <p>Route guidance with voice output and visual display. OpenStreetMap data, offline-capable — no data connection required once maps are loaded.</p>
        <span class="feature-status status-dev">In Development</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">◉</span>
        <h3>Green Vector Display Mode</h3>
        <p>Phosphor-green vector graphics on dark background. Roads as lines, gauges as arcs and needles. Requires 480p+ display and modest GPU acceleration.</p>
        <span class="feature-status status-dev">In Development</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">◎</span>
        <h3>Offline Map Engine</h3>
        <p>Custom vector renderer reading OpenStreetMap PBF extracts. No internet required. Pre-packaged regional map sets for easy installation.</p>
        <span class="feature-status status-dev">In Development</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">◫</span>
        <h3>Camping &amp; Trip Planner</h3>
        <p>Multi-stop route planning with campsite integration, fuel stop calculations and overnight halt logging. Designed for the long-distance touring use case.</p>
        <span class="feature-status status-planned">Planned</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">⊛</span>
        <h3>Home Automation Bridge</h3>
        <p>MQTT integration for remote vehicle monitoring. Track location and vehicle status from home. Receive alerts for out-of-range temperatures or fault codes.</p>
        <span class="feature-status status-planned">Planned</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">⊞</span>
        <h3>Journey Logging</h3>
        <p>Automatic GPX track recording. Annotate journeys with notes and photos. Review routes and vehicle data after the fact.</p>
        <span class="feature-status status-planned">Planned</span>
      </div>
      <div class="feature-card">
        <span class="feature-icon">◧</span>
        <h3>Voice Control</h3>
        <p>Offline voice commands for destination entry and system control — no cloud service, no internet connection, no privacy concerns.</p>
        <span class="feature-status status-planned">Planned</span>
      </div>
    </div>
  </div>
</section>
